# Projet_Pyspark_Databricks
Projet réalisé sur Databricks avec PySpark à partir d’un dataset e-commerce (clients, commandes, produits, vendeurs, paiements, avis). L’objectif était de construire un pipeline ETL complet : nettoyage, transformation et création d’indicateurs analytiques pour évaluer les performances commerciales, logistiques et le comportement client.
